AF2 distogram audit, 14 October 2026

Recovered original WT and AA tar archives from the user's Dropbox link. Both archive SHA256 values match the supplied manifest. All five models per sequence were read, and rank-1 PDB coordinates exactly match the prediction.pdb used for the original simulation. Sequence length and residue mapping match the 120-residue topology.

Both rank-1 structures contain nine DSSP alpha-helical residues at AR394-402. The raw rank-1 distograms have i,i+4 peaks near 0.622 nm within this region. These are real helical distance signals, not absent predictions.

The original preprocessing uses the authors' tutorial's residue-specific contact cutoff and excludes all sequence separations <=3. The alanine-alanine cutoff is 0.5381 nm. Consequently it rejects the 0.621875 nm modes for these helical i,i+4 pairs. Only one selected restraint has both endpoints within the WT AR394-402 helix; AA has none. Similar sparsity occurs across all five AF2 models. The surviving WT pair involves W397, whose larger residue-specific cutoff admits it. Changing W397 to alanine also changes restraint selection, beyond changing the physical residue.

Independent float64 softmax selection reproduces exactly the original 19 WT / 15 AA pairs. Refitting with the supplied low-precision input path changes means/widths by at most 0.000379 nm WT / 0.000514 nm AA relative to saved parameters; these are tiny numerical differences, not enough to explain disappearing helicity. Exported NPY probabilities and float64 normalization differ by <0.000715 absolute probability, consistent with float16 storage. Probability symmetry is exact.

The filter is present in upstream bAIes source and its example invocation. This is a loss of information at selection, not a demonstrated indexing or softmax implementation bug. It is not proof that the filter alone explains all poor experimental agreement. The previous audit was too narrow: reproducing the parameter file did not establish adequate retention of helical information.
